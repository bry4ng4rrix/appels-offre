NOTES TECHNIQUES POUR L'INTEGRATION
====================================================================================
- APIs ouvertes / JSON faciles a scraper : ReliefWeb, PNCP (Bresil), SECOP II (Colombie),
  Contracts Finder (UK), SAM.gov (USA - cle API gratuite), CanadaBuys (CSV/JSON quotidiens).
- Portails E-Procurement (Rwanda, Tanzanie, Ouganda, Zambie, Ethiopie) : reposent souvent
  sur des architectures similaires (portails web modernes avec endpoints REST internes XHR).
- Sites WordPress (nombreuses agences locales/ONG) : tester systematiquement /wp-json/wp/v2/posts
  ou /feed/ avant d'ecrire un parser HTML complet.
