6. ASTUCE POUR DECOUVRIR D'AUTRES APIs RAPIDEMENT
====================================================================================
- Moteur OpenDataSoft : Beaucoup de portails publics francophones et europeens utilisent
  OpenDataSoft (comme votre source BOAMP). Le chemin /api/explore/v2.1/catalog/datasets/
  est presque toujours actif.
- Standard OCDS : Rechercher "<Nom du pays> OCDS API" permet de trouver instantanement
  les endpoints JSON standardises qui utilisent tous exactement le meme schema de donnees
  (un seul parser Python suffit pour aspirer 10+ pays differents).
