NOTES RELIEFWEB :
- Endpoint emplois : https://api.reliefweb.int/v2/jobs
- Ajouter appname=VOTRE_NOM_APPLICATION a chaque requete.
- Exemple : https://api.reliefweb.int/v2/jobs?appname=mon_app&limit=50
- Champs utiles : title, url, date.created, date.closing, status, country.name, source.name.
- Documentation : https://apidoc.reliefweb.int/read/resources/jobs/
- L API fournit les donnees en JSON via HTTPS.

=== RECOMMANDATIONS TECHNIQUES ===
1. Ajouter d abord ReliefWeb Jobs : c est l API la plus directement utile pour les emplois, missions et ONG.
2. Ajouter ensuite les APIs de donnees ouvertes : data.europa.eu, data.gov.uk, data.gov.us, GovData, Canada Open Government et Data.gov.au.
3. Ajouter les APIs de la Banque mondiale pour enrichir les projets avec des indicateurs pays.
4. Ajouter Adzuna et Jooble si vous voulez elargir la couverture emplois au-dela du secteur ONU et ONG.
5. Pour Greenhouse et Lever, utiliser les endpoints publics de job boards quand ils sont disponibles ; ils sont surtout utiles pour les entreprises et ONG qui recrutent via ces plateformes.
6. Ne pas considerer UNGM comme API gratuite : l acces API general a ete refuse dans votre registre ; utiliser une veille ou un scraping respectueux si les conditions le permettent.
7. Verifier les limites de requetes, les conditions d utilisation et la politique de confidentialite avant l integration.

=== EXEMPLE RELIEFWEB JOBS ===
GET https://api.reliefweb.int/v2/jobs?appname=mon_app&limit=50

Exemple de parametres utiles :
- appname=mon_app
- limit=50
- sort[]=date:desc
- filter[field]=status
- filter[value]=active
